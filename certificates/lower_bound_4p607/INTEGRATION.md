# Public repository integration

This package was imported from Mira-Cult/17squares commit
`0277023a9e93a3801df17b0d7ea69aecac1be9ac`, which integrated the original
`17squares-record-4p607.patch`. The exact measure, checkers, source data,
controls, audit logs and discovery inputs are retained from that revision.
Upstream attribution remains in `ATTRIBUTION.md`.

The public repository at https://github.com/Mira-acc/17squares updates its main
paper, rendered PDF, README, verification guide and citation metadata for the
weighted theorem. Its own historical `4.468292` triangle-witness package is
preserved, and that proof forms the paper's appendix. `verify_all.sh` runs
weighted replay followed by the historical deterministic reproduction.

The local package manifest covers the imported files and these adapted
integration notes. Historical source hashes and certificate hashes are
unchanged. External peer review remains pending.
